# T6: Wrong signing identity

- Image digest: `sha256:340cf531d9b51f9f2466e34fd771b1f2c0a754d59143cec5ddb2dbf06c8e546f`
- Result: **Pass**

The image was signed with a personal Cosign keyless identity using the Sigstore
device flow. Unrestricted Cosign verification succeeded. The image was then
submitted to kind and Kyverno denied it with:

```text
Failed to verify the container image signature
```

The test pod was deleted after the denial.
